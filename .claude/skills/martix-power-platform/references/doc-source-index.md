## Training path

The research processed all six modules and their 46 units in
[Build custom connectors for Microsoft Power Platform](https://learn.microsoft.com/en-us/training/paths/build-custom-connectors/):

1. Get started with custom connectors.
2. Configure custom connectors with authenticated APIs.
3. Create triggers for custom connectors.
4. Use custom code in custom connectors.
5. Configure policy templates for custom connectors.
6. Create OpenAPI custom connectors.

Use the training modules for implementation examples and conceptual sequence;
use the current product pages for limits, support status, and production claims.
